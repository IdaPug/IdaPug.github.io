### [3D Medical Image Segmentation Using DINO Feature Representations](https://github.com/IdaPug/3D-Medical-Image-Segmentation-Using-DINO-Feature-Representations)
*Master's thesis — DTU Compute · supervised by Anders Bjorholm Dahl and William Michael Laprade*

<img align="right" width="320" src="images/seg_comparison.jpg" alt="Comparison of segmentation results across sagittal, axial and coronal CT slices">

Investigated whether feature representations from the DINOv3 vision transformer could improve 3D medical image segmentation when integrated into a traditional U-Net architecture — with the explicit goal of relying on a small amount of manually annotated training data. Built an end-to-end pipeline covering preprocessing, model development, validation, and performance analysis on large-scale, high-dimensional CT volumes, and evaluated three model variants against a vanilla U-Net baseline.
